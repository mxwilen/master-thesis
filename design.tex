\chapter{Design of ...}
\label{cha:design}

If a prototype system has been developed, this needs to be described here. Replace ``...'' in the title with the name of your system or something descriptive. Some hints for writing this chapter:

\begin{itemize}
\item Use figures!
\item Figures should either be drawn by you, or carefully cited in the caption.
\item Figures should always be referenced in the text, and explained in the text what they represent/contain.
\item You should start with a structural overview of your prototype/system.
\item Show clearly what parts you have created, and which parts that were already existing when you started. Remember that aseembling existing components can also be a contribution.
\item Avoid programming code and strangely-sounding variable/function names.
\item You are free to call a module something else than what it is called in the source code.
\item Always have the reader in mind when writing. Be pedagogic.
\end{itemize}
